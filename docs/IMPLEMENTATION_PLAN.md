## 1. MVP-First Prioritization Strategy (`CONFIRMED` / `PROPOSED`)

Implementation strictly targets **Slice 1: Core Lifecycle MVP**. To minimize rework and prevent security shortcuts during AI-assisted development in Google Antigravity, execution follows a **Foundation-First, Vertical-Slice** strategy (`PROPOSED`):

1. **Security & Isolation First:** Establish PostgreSQL schema, `app_user` (`NOBYPASSRLS`), forced Row-Level Security (RLS), `withTenantContext()`, Better Auth, and RBAC policies before writing any SOP business logic.
2. **Cryptographic & Audit Core Early:** Build the `SHA-256` payload hasher (`DEC-06`) and serialized append-only hash-chained audit service (`DEC-08`) before implementing workflows so every mutation is audited from its first commit.
3. **Strict Slice Discipline:** Do **NOT** implement Slice 2 (parallel/quorum approvals, delegation, 48h/96h escalations, visual `.docx` diffing) or Slice 3 (SAML 2.0 SSO, SCIM, webhooks, Enterprise API, FDA Part 11 package, native offline apps) as Slice 1 dependencies.
